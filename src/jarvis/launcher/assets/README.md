# Jarvis launcher icon

`jarvis.png` is the original transparent image generated with the built-in
Codex ImageGen tool on 2026-10-16. `jarvis.ico` is its deterministic Windows
export, containing PNG frames at 16, 20, 24, 32, 40, 48, 64, 128, and 256 px.
Regenerate the ICO from the repository root with:

```powershell
tools/build_launcher_icon.ps1
```

Final generation prompt:

Create one finished Windows desktop application icon for Jarvis, a private
local voice and vision assistant. Icon only, no mockup, no presentation.
Center a bold, highly recognizable abstract J symbol combined with a minimal
listening aperture / audio core. Geometric precision, a few thick shapes and
generous negative space that still read at 16 pixels. Premium restrained
industrial software identity, not a robot face, not Iron Man, not a generic
microphone drawing. A rounded-square deep graphite tile #0A0D14 with crisp
bright mint cyan #3FE0D0 mark and a very restrained dimensional edge, subtly
luminous but no fuzzy outer glow. Straight-on view, square image, tile fills
90 percent of the canvas. Outside the rounded tile genuinely transparent.
No words, no caption, no background scene, no tiny details or decorative
circuits. This is the final app icon asset, not a logo exploration.
